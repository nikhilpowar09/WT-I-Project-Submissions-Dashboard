## 🛠️ Infrastructure Overview

The application features a built-in heuristic parsing script that scans incoming project profiles and automatically routes them based on their tech stacks, platforms, and operational segments.

### Key Engineering Features:
* **Zero-Flicker Theme Engine:** Native dark/light mode switching utilizing decoupled CSS variables.
* **Edge Infrastructure Tracker:** Real-time counters calculating live target deployments across **GitHub Pages**, **Vercel**, and **Netlify**.
* **Smart Segment Directories:** Automated keyword mapping to isolate project arrays into clean logical views:
  * 🧑‍💻 Developer Portfolios
  * 🛍️ E-Commerce / Retail Applications
  * ☕ Food & Hospitality Systems
  * 🏎️ Automotive Tech Solutions
* **Live Search Processing:** Instant front-end filter matrix targeting developer names, custom domain patterns, or cloud host indicators.
